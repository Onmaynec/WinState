# Security Policy

WinState находится на раннем архитектурном этапе и пока не изменяет системную конфигурацию Windows.

Не публикуйте уязвимости в открытых Issues. Используйте GitHub Security Advisories репозитория. В сообщении укажите затронутую версию, сценарий, ожидаемое влияние и безопасный способ воспроизведения без реальных секретов.

Подробная модель: [docs/SECURITY.md](docs/SECURITY.md).
