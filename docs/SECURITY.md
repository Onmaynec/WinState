# 🛡️ Модель безопасности

## Запреты по умолчанию

- нет скрытых системных изменений;
- нет массового удаления неизвестных ресурсов;
- нет запуска произвольных скриптов;
- нет автоматической перезагрузки;
- нет сохранения токенов, паролей и приватных ключей;
- нет критических операций без отдельного разрешения.

## Доверительная граница профиля

Профиль считается входными данными, а не доверенным кодом. Путь нормализуется, includes ограничиваются каталогом профиля, архивы проверяются от ZIP Slip, а скрипты в будущих версиях потребуют SHA-256 и явного `--allow-scripts`.

## Повышение прав

CLI не должен постоянно работать от администратора. План сначала строится с обычными правами, после чего elevation запрашивается только при наличии соответствующих действий.

## Логи

Секретные значения маскируются. В логах допустимы только `secretRef`, имя ресурса, операция и безопасные диагностические данные.
