# WinState 1.0.0 — Workspace Control и безопасное восстановление

WinState 1.0.0 — первый major stable release. Он расширяет управление Windows до воспроизводимого пользовательского рабочего окружения и добавляет recovery-сценарий для updater backup.

## Что нового

### Workspace Control

- глобальные настройки Git как код;
- PowerShell modules для `CurrentUser`;
- управляемые UTF-8 файлы и каталоги;
- JSON manifest schema version 1;
- deterministic plan с рисками и объяснениями;
- отдельные gates `--allow-modules` и `--allow-delete`;
- persisted transaction manifest после каждого действия;
- автоматический rollback обратимых действий при ошибке;
- ручной rollback завершённой транзакции;
- idempotent повторный plan.

### Ownership

- постоянный versioned ownership ledger;
- удаление только ресурсов, ранее принятых под управление WinState;
- запрет удаления чужих Git settings, файлов и каталогов;
- запрет удаления непустых каталогов;
- PowerShell modules автоматически не удаляются;
- безопасная миграция и блокировка более новой неизвестной schema.

### Отчёты

- JSON-отчёт каждого Workspace plan/apply;
- Markdown-отчёт для ревью;
- атомарная запись отчётов;
- action IDs, risks, destructive/irreversible flags и rollback capability.

### Восстановление обновления

- команда `winstate update restore`;
- проверка структуры updater backup;
- safety backup текущей установки;
- сохранение `.winstate`, `profiles` и `logs`;
- отложенный PowerShell restore после завершения процесса;
- `restore-success.txt` и диагностический `restore-error.log`.

### Stable pipeline

- версия приложения и package marker `1.0.0`;
- Ubuntu/Windows CI;
- настоящий Workspace vertical slice `validate → plan → apply → idempotency → rollback`;
- recovery smoke test;
- self-contained `win-x64` и `win-arm64` archives;
- SHA-256 и `SHA256SUMS`;
- условная Authenticode подпись официальным сертификатом, когда signing secrets настроены;
- стабильный Release автоматически становится **Latest**.

## Быстрый старт

```powershell
.\winstate.exe workspace validate .\workspace.json
.\winstate.exe workspace plan .\workspace.json --report .\reports
.\winstate.exe workspace apply .\workspace.json --yes --report .\reports
.\winstate.exe workspace status
```

Для manifest с PowerShell modules:

```powershell
.\winstate.exe workspace apply .\workspace.json --yes --allow-modules
```

Для управляемых удалений:

```powershell
.\winstate.exe workspace apply .\workspace.json --yes --allow-delete
```

Откат:

```powershell
.\winstate.exe workspace rollback <transaction.json> --yes
```

Восстановление updater backup:

```powershell
.\winstate.exe update restore <backup-directory> --yes
```

## Безопасность

- plan не изменяет систему;
- apply требует явный `--yes`;
- module install и deletion разрешаются независимо;
- существующие файлы копируются в checkpoint перед заменой или удалением;
- Git config восстанавливается до исходного значения;
- ownership обновляется только после успешного действия;
- неизвестная новая persisted schema блокирует mutation;
- Authenticode marker честно отражает, была ли сборка подписана;
- SHA-256 остаётся обязательным для каждого archive.
