# WinState 0.9.0 — Снимки состояния и контроль отклонений

## Что нового

- добавлена команда `capture` для экспорта текущей конфигурации Windows в проверяемый YAML-профиль;
- рядом со снимком создаётся JSON-манифест с SHA-256, временем создания, версией WinState и количеством ресурсов;
- добавлена команда `drift` для поиска отличий между текущей системой и декларативным профилем;
- JSON-отчёт drift содержит действия, риски, требования администратора, поддержку отката и диагностику провайдеров;
- добавлены стабильные коды завершения для автоматизации: `0` — отклонений нет, `10` — отклонения обнаружены;
- Capture экспортирует переменные окружения, PATH, установленные пакеты WinGet и включённые компоненты Windows;
- потенциальные пароли, токены, ключи, credentials и строки подключения автоматически исключаются из снимка;
- запись YAML, манифеста и JSON-отчёта выполняется атомарно;
- CLI и документация обновлены и оформлены на русском языке;
- добавлены unit-тесты и Windows CI-сценарий `capture → validate → drift`.

## Безопасность

- `drift` выполняет только discovery и построение плана — система не изменяется;
- секретоподобные переменные не попадают в YAML;
- массовое удаление неизвестных ресурсов не выполняется;
- captured package scope необходимо проверить вручную перед применением;
- снимки не заменяют резервную копию Windows.

## Файлы релиза

- `WinState-0.9.0-win-x64.zip` — переносная self-contained сборка для Windows x64;
- `WinState-0.9.0-win-arm64.zip` — переносная self-contained сборка для Windows ARM64;
- индивидуальные файлы `.sha256`;
- общий файл `SHA256SUMS`.

## Быстрый старт

```powershell
.\winstate.exe capture .\profiles\my-pc.yaml "Мой компьютер"
.\winstate.exe drift .\profiles\my-pc.yaml .\reports\drift.json
```

Это обычный стабильный релиз GitHub, не предварительная версия. После публикации он отмечается как **Latest**.
