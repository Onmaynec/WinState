# Снимки состояния и контроль отклонений

WinState 0.9.0 добавляет безопасный цикл наблюдения за конфигурацией Windows без изменения системы:

```text
текущее состояние → capture → YAML + манифест + SHA-256
профиль → discovery → plan → drift report
```

## Создание снимка

```powershell
.\winstate.exe capture .\profiles\my-pc.yaml "Мой компьютер"
```

Команда собирает:

- пользовательские и системные переменные окружения;
- пользовательский и системный `PATH`;
- установленные пакеты WinGet;
- включённые дополнительные компоненты Windows.

Рядом с YAML создаётся файл `<имя>.yaml.snapshot.json` с временем создания, версией WinState, именем компьютера, количеством ресурсов и SHA-256 профиля.

## Защита секретов

Capture не записывает переменные, имя которых похоже на пароль, токен, ключ, credential, строку подключения или другой секрет. Также не экспортируются значения с синтаксисом шаблонов WinState, если они могут быть ошибочно интерпретированы при загрузке профиля.

WinState никогда не считает автоматически собранный YAML полностью готовым к применению. Перед `apply` необходимо просмотреть:

- scope пакетов WinGet;
- системные переменные;
- точные версии пакетов;
- список включённых компонентов Windows.

## Проверка отклонений

```powershell
.\winstate.exe drift .\profiles\my-pc.yaml .\reports\my-pc.json
```

Drift выполняет только чтение состояния и построение Unified Apply Plan. Никакие системные изменения не применяются.

Коды завершения:

| Код | Значение |
|---:|---|
| `0` | отклонений нет |
| `10` | обнаружены отклонения |
| `3` | профиль не прошёл проверку |
| `6` | необходимый провайдер недоступен |

JSON-отчёт содержит:

- имя и путь профиля;
- время проверки;
- количество изменений;
- максимальный риск;
- опасные действия;
- требования администратора;
- поддержку отката;
- диагностические сообщения провайдеров.

## Использование в автоматизации

```powershell
.\winstate.exe drift .\profiles\workstation.yaml .\reports\drift.json
if ($LASTEXITCODE -eq 10) {
    Write-Warning "Конфигурация Windows отклонилась от профиля"
}
```

Для регулярной проверки рекомендуется хранить YAML-профили в Git, а JSON-отчёты — как артефакты CI или локальные журналы. Снимки не заменяют резервное копирование Windows.
