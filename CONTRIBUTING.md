# 🤝 Участие в разработке WinState

1. Создайте отдельную ветку.
2. Не смешивайте UI и системную бизнес-логику.
3. Не добавляйте destructive behavior без risk classification, confirmation и тестов.
4. Публичные API документируйте XML-комментариями.
5. Не оставляйте пустые `catch`, критические `TODO` и псевдокод.
6. Выполните `dotnet build` и `dotnet test`.
7. В PR опишите влияние на безопасность и rollback.
